# Metacognitive Reasoning Bundle

Enhanced problem-solving through structured thinking patterns.

## What This Provides

This bundle enhances AI reasoning with metacognitive patterns:

- **Think-before-acting**: Structured problem decomposition
- **Self-monitoring**: Awareness of reasoning quality
- **Strategy selection**: Choosing appropriate approaches
- **Reflection**: Learning from reasoning processes

## Core Principles

1. **Explicit reasoning** - Make thinking visible and traceable
2. **Iterative refinement** - Improve through reflection
3. **Adaptive strategies** - Match approach to problem type
4. **Quality awareness** - Monitor and improve reasoning

## Usage

```bash
amplifier run --bundle metacognition "Solve this complex problem..."
```

The metacognitive patterns will guide the AI through structured reasoning.
